# Changelog

Super Forms ships on two customer channels:

* [**Stable**](changelog-stable.md) is the default install (~95% of users). Receives compatibility releases and critical fixes. **Current release: v6.3.314** (Jul 07, 2026).
* [**Beta**](changelog-beta.md) is opt-in for early access to new features. **Current release: v6.4.005-beta** (Jul 09, 2026).

To switch your install between channels, see the [BETA version](developers/beta-version.md) guide.

For internal development / unreleased commit history see the [super-forms GitHub repository](https://github.com/RensTillmann/super-forms).
