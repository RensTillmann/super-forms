# Changelog

Super Forms is released on two channels:

* [**Stable**](changelog-stable.md) is installed by default. It receives compatibility releases and critical fixes. **Current release: v6.3.323** (Oct 20, 2026).
* [**Beta**](changelog-beta.md) is opt-in and gives early access to new features. **Current release: v6.4.010** (Oct 21, 2026).

To switch a site between channels, see the [BETA version](developers/beta-version.md) guide.

For development history and unreleased changes, see the [super-forms GitHub repository](https://github.com/RensTillmann/super-forms).
