# E-mail Notification

To change your account notification settings, open [dashboard.super-forms.com](https://dashboard.super-forms.com) and sign in.

Open **Notification Settings** (Quick Actions).

By default you should receive notifications about your license expiring, notifications about payment/billing issues and notifications about new invoices.

You can add more recipients if required with each their own notification settings.

After you made changes click **Save Notification Settings**.

{% hint style="info" %}
From WordPress, **Super Forms > Licenses** opens a shortcut to the same dashboard. Notification settings are separate from **Account Settings**.
{% endhint %}
