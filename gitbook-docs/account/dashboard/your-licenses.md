# Your Licenses

Your licenses live in the Super Forms account dashboard at [dashboard.super-forms.com](https://dashboard.super-forms.com). Sign in, then open **Licenses**. Unused codes sit under **Unused License Codes**; codes already tied to a site appear with that site.

{% hint style="info" %}
From WordPress, **Super Forms > Licenses** opens a shortcut to this dashboard.
{% endhint %}

To activate an unused code on a site: open **Unused License Codes** → **Activate License** → enter that site's domain.

### Move a license to another domain

1. Sign in at [dashboard.super-forms.com](https://dashboard.super-forms.com).
2. Open the website card for the current domain (click it to expand).
3. On the licence row, click **Transfer to Domain**.
4. In the **Transfer License** window, enter the new domain under **New Domain** (`example.com` or `https://example.com`).
5. Optional: tick **Validate domain before transfer** to check that Super Forms is installed on the new site. Leave it unticked if the site isn't live yet.
6. Click the transfer button. The licence moves at once, and the old domain loses access.

{% hint style="info" %}
You can transfer a licence once every 24 hours. You can't transfer to a domain that already has a licence for the same product (renew or release that licence first). Development domains (localhost, `*.local`, and similar) don't need a licence.
{% endhint %}

### Free up a one-time licence for later

For one-time (non-subscription) licences only, you can click **Release** on the licence row. The code returns to **Unused License Codes**. Then click **Activate License** and enter the new site's domain.

{% hint style="warning" %}
Subscription licences have no **Release** button. Use **Transfer to Domain** instead.
{% endhint %}

### Rename a site's domain for every product on it

On the website card, click the pencil icon (**Edit domain for all products**), edit the domain, and save.
